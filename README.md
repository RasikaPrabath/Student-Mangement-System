# Galle Academy - Student Management System

A modern, responsive, and seamless Student Profile & Academic Management System built with HTML5, CSS3, and JavaScript.

## Features
- **Student Profile & Academic Dossier**: Complete overview of student information, bio, contact details, and emergency contacts.
- **Academic Analytics & Performance**: Term-by-term score tracking, GPA calculation, subject breakdowns, and interactive grade radar charts.
- **Spotlight Search**: Fast real-time search by admission number, name, or quick-filter chips.
- **Student Registration**: Form to register and manage student records.
- **CSV Data Exchange**: Export and import student data seamlessly via CSV.
- **Print Dossier**: Formatted print layout for generating official academic profile sheets.
- **Dark / Light Theme**: Built-in sleek dark and light mode toggle.

## Project Structure
```
├── assets/              # Crest and student profile pictures
├── index.html           # Main web interface
├── styles.css           # Styling, themes, and responsive design
├── app.js               # Application logic, charts, and interactivity
└── students_data.js     # Default student datasets & persistence helpers
```

## Getting Started
Simply open `index.html` in any modern web browser or serve via a local static web server (e.g. Live Server, Vite, or Python `http.server`).
